# 사투리 코치 (DialectCoach)

배우를 위한 사투리 연기 연습 웹앱입니다. 표준어 독백을 넣고 지역을 고르면 사투리 대본으로 바꿔 주고, 음성인식으로 읽기 연습을 채점해 줍니다.

- **지원 지역**: 한국어 7곳(경상 2·전라·충청·강원·제주·북한), 영어 6곳, 중국어 4곳
- **AI**: ChatGPT(OpenAI) 또는 Claude 중 키가 있는 쪽을 사용 (키가 없으면 데모 모드)
- **기능**: ① 사투리 변환 + 바뀐 이유 설명 ② 음성인식 연습·일치율 채점 ③ 브라우저 음성으로 듣기(베타)

> ⚠️ 사투리 규칙은 공개 자료 조사 결과이며 일부는 검증이 덜 되었습니다(`research-review.md` 참고). 오디션·촬영 전에는 꼭 그 지역 출신에게 확인받으세요.
